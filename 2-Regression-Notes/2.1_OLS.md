1. Closed Form VS Open Form
- A closed-form solution uses a direct mathematical formula with a finite number of standard operations to find an exact answer, while an open-form solution relies on iterative, recursive, or infinite processes (like loops or numerical approximations) to approach the answer over time.
- Closed-Form SolutionDefinition: An explicit mathematical expression that yields the final result in a fixed number of steps using standard operations (addition, roots, exponents, trig functions).Speed: Highly efficient because you plug in numbers and instantly get the result (\(O(1)\) or logarithmic time complexity).Accuracy: Yields an exact mathematical value (barring standard computer floating-point rounding limits).Examples: The quadratic formula for \(ax^2 + bx + c = 0\), or the normal equation in linear regression ($w = (X^TX)^{-1}X^Ty$).
Open-Form SolutionDefinition: A recursive, iterative, or series-based approach where each step depends on previous steps or requires a running approximation until convergence.Speed: Slower for large inputs, as computation scales with the number of iterations or recurrence depth (\(O(n)\) or worse).Accuracy: Yields an approximation that gets closer to the true answer the longer you run it.Examples: Gradient descent in machine learning (iteratively updating weights), standard recursive definitions of the Fibonacci sequence (\(F_n = F_{n-1} + F_{n-2}\)), or numerical integration

-   A model is non-linear if it is not linear in its parameters. An example is $ \(y = \beta_0 e^{\beta_1 x}\) $, where the parameter β₁ is in the exponent.Requires iterative numerical optimization algorithms (such as Levenberg-Marquardt or Gauss-Newton) to approach the minimum step-by-step.
-   In linear regression, "linear" means the model must be linear in its parameters (coefficients), but the raw $\[X\]$ and $\[Y\]$ data can sometimes have a transformed or curved relationship as long as the coefficients remain in a simple additive and multiplicative first-power form.
-   Linear in Parameters vs. Linear in VariablesLinear in Parameters (The True Mathematical Requirement): The model expresses the dependent variable $(\[Y\])$ as a weighted sum of parameters $(\[\beta \])$, written as $\(Y = \beta_0 + \beta_1X_1 + \beta_2X_2 + \epsilon\)$. The coefficients (\[\beta \]) must be raised only to the first power, and they cannot be multiplied together or divided by another coefficient. MediumLinear in Variables (\[X\] and \[Y\] Relationship): While classic linear regression assumes the expected value of \[Y\] has a straight-line relationship with \[X\], you can still model non-linear relationships (like curves) by feeding transformed variables into the equation—such as using \[X^{2}\] or \(\log(X)\) as features (e.g., \(Y = \beta_0 + \beta_1X + \beta_2X^2\)). This model is still considered a "linear regression" because it is linear in the parameters (\[\beta \]), even though the \[X\]-to-\[Y\] graph is curved
